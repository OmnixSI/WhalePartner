# 角色闪卡网页预览

独立预览使用当前客户端的字体、色彩与角色徽记，不挂载聊天页，不调用 API，也不连接 SQLite。页面内的角色选择和关系阶段仅保存在当前页内存；切换卡片不会改动应用角色。

当前只有大肥鱼绑定可用的 Live2D 模型。小克、小智和鲸汐继续展示各自固定的矢量默认形象，并明确标出没有额外可用的 Live2D 模型。

## 启动

在仓库根目录运行：

```sh
pnpm --dir apps/client dev -- --host 127.0.0.1 --port 1420
```

打开 <http://127.0.0.1:1420/character-cards.html>。不需要启动 API。

## 演示内容

- 四位角色的牌库、选择反馈及各自模型归属。
- 四档固定关系样本。数字、阶段和“默契”解锁点均为界面演示值，不代表真实关系规则或用户数据。
- 基础卡面始终可选择；高阶细闪可在解锁样本中手动开关。
- 鼠标悬停支持轻微视角变化；卡片按钮支持键盘和触摸；减少动态效果偏好会停止光带和视角动画。

进度规则尚未接入关系成长服务。角色闪卡应用内入口与真实解锁状态等待用户验收本网页后再集成。

## 浏览器检查与截图

保持 Vite 页面运行，在仓库根目录执行：

```sh
pnpm --dir apps/client run card-preview:check
```

检查会验证角色选择不写入 `wp.character`、无 API 请求、键盘/触摸操作、解锁状态、减少动态效果、字号缩放和窄屏横向溢出。固定数据不含异步加载、网络错误或空牌库路径，因此这些状态不适用于此预览。

截图保存在 `docs/redesign/shots/character-cards/`：1440 × 960 桌面锁定与解锁效果、390 × 844 窄屏概览与触摸选中状态。
