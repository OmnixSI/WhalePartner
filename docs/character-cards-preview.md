# 角色闪卡网页预览

独立预览使用当前客户端的字体、色彩、角色徽记与卡牌材质，不挂载聊天页，不调用 API，也不连接 SQLite。页面内的角色选择和关系阶段仅保存在当前页内存；切换卡片不会改动应用角色。

当前只有大肥鱼绑定可用的 Live2D 模型。预览在唯一的主卡舞台中真实加载该模型，支持触摸互动和已配置的表情；牌库缩略卡不会初始化额外渲染器。小克、小智和鲸汐继续展示各自固定的矢量默认形象，不借用大肥鱼模型。模型署名与许可可在主卡详情展开查看。

## 启动

在仓库根目录运行：

```sh
pnpm --dir apps/client dev -- --host 127.0.0.1 --port 1420
```

打开 <http://127.0.0.1:1420/character-cards.html>。不需要启动 API。

## 演示内容

- 四位角色的牌库、选择反馈及各自模型归属。
- 主卡中的真实 Live2D 舞台、预配置表情、点击动作和可见载入/失败状态；目前只有大肥鱼模型可以这样显示。
- 五级卡面效果与关系样本联动：Lv.1 普通静态卡面、Lv.2 倾斜与分层视差、Lv.3 动态灯光和立体光环、Lv.4 专属星芒粒子、Lv.5 角度响应的全息镀闪 Shader。
- 深海蓝立绘底、金属层叠卡框、能量光环与动态光照；Live2D 目标高度为舞台的 108%、宽度为 102%，从卡面主要区域呈现人物。
- 卡面倾斜时，金属背板、场景光、Live2D 人物和光环按不同幅度视差移动；Lv.5 的镭射色散由倾角驱动，并叠加中心立绘遮罩、边缘 Fresnel、交叉扫光和柔边星芒。
- 五档固定关系样本。阶段名称、点数和阈值仅供网页演示，不代表真实关系规则或用户数据。
- 基础角色始终可选；牌库卡片与主卡支持键盘、鼠标和触摸；减少动态效果偏好会停用视差动画、CSS 动画和 Shader 连续渲染。

运行前需在当前工作区准备 `apps/client/public/live2d/whale-maid/` 的模型资源及 `apps/client/public/live2d/libs/live2dcubismcore.min.js`。它们由 `.gitignore` 排除；模型采用 CC BY-NC-SA 4.0，Cubism Core 为 Live2D 专有组件，因此不提交模型或 Core。仅本机预览和本地构建使用这些资源。

卡面截图中的模型署名：角色原作上善无形，DeepSeek 女仆设计 ZipZipPipe，Live2D 建模氵六青，发布仓库 [A8Chann/dsh-pet-live2d](https://github.com/A8Chann/dsh-pet-live2d)；模型适用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)。

## 卡面效果依据

公开资料将五级效果描述为基础卡面、立体、动态画面、专属特效和镀闪（[效果说明](https://www.sohu.com/a/1057939968_122743460)）；版本更新记录了 17 个英雄的卡面升级特效迭代（[体验服更新公告转载](https://a.4399.cn/gg/53760390_250086.html)），另有公告记录过 3 级以上卡面特定角度显示异常的修复（[卡面问题修复](https://wzwxq.com/updates/official/18731495)）。公开检索未找到《王者万象棋》卡面渲染源码或直接复刻项目，本预览复刻视觉层级，不复制游戏资源或宣称还原官方 Shader。

实现参考了开源 [3D TCG Card Renderer](https://github.com/BrannySG/card-renderer) 的倾角色散、遮罩镀膜、Fresnel 高光、交叉扫光和星点分层，以及 [cards-css](https://github.com/kongyo2/cards-css) 的指针/陀螺仪响应式闪膜思路；预览使用现有 Live2D 角色，不引入这些项目作为运行依赖。

进度规则尚未接入关系成长服务。角色闪卡应用内入口与真实解锁状态等待用户验收本网页后再集成。

## 浏览器检查与截图

保持 Vite 页面运行，在仓库根目录执行：

```sh
pnpm --dir apps/client run card-preview:check
```

检查会真实加载本机模型并验证渲染器仅有一个实例、人物占比、五级效果、Shader 实际编译、粒子数量、视差反馈、角色归属、切换等级不重载模型、角色选择不写入 `wp.character`、无 API 请求、键盘/触摸操作、待解锁提示、减少动态效果、字号缩放和窄屏横向溢出。加载错误由舞台提供重试；牌库与关系样本固定，不连接业务数据。

截图保存在 `docs/redesign/shots/character-cards/`：Lv.1 静态卡面、Lv.2 视差、Lv.3 动态灯光、Lv.4 专属粒子、Lv.5 桌面镀闪、独立主卡特写、390 × 844 窄屏概览与触摸选中状态；桌面图包含大肥鱼的 Live2D 主卡。
