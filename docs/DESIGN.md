# 界面与美术规范

客户端（`apps/client`）的视觉方向叫“深海晨光”：二次元的柔和质感，海洋与鲸的气质，手机优先。所有页面沿用同一套 token，新增界面先查本文件。

## 方向

- **角色**：鲸汐，原创鲸系 AI 角色。不使用 DeepSeek 名称或 Logo，不复用社区已有的鲸鱼娘设定。
- **气质**：晨光浅滩（亮色）和夜间深海（暗色）两套配色，同一个角色在两种光线下都成立。
- **记忆点**：角色站在会呼吸的海水里：光束缓慢摇动，气泡上浮，底部两层波浪错速漂移。

## Token

定义在 `apps/client/src/styles/tokens.css`，亮色在 `:root`，暗色在 `prefers-color-scheme: dark` 和 `[data-theme="dark"]` 下覆盖。设置页可选“跟随系统 / 晨光 / 深海”，选择存在 `localStorage`，读写失败时回退到跟随系统。

| 角色 | 亮色 | 暗色 |
|---|---|---|
| 背景 | `#eaf6f6` → `#a9dcdc` 渐变 | `#0a2a47` → `#05101f` 渐变 |
| 面板 | 白 72% 毛玻璃 | `#0e2842` 62% 毛玻璃 |
| 主色 | 潮汐青 `#087f68` | 泡沫青 `#5fd6c4` |
| 强调 | 晨光珊瑚 `#ff8a7a`（徽标圆点、导航指示条、气泡点缀） | 同左 |
| 正文 | `#12313a` | `#e6f4f4` |

圆角 12 / 18 / 26 px；阴影柔和，不用硬边框强调层级。

## 字体

- 角色的话和标题：霞鹜文楷（LXGW WenKai，OFL），按 unicode-range 分片加载，首屏只下载用到的字。
- 拉丁装饰字：Fraunces Variable（OFL），只用于小标题和英文副标。
- 界面正文：系统 UI 字体（PingFang SC / 微软雅黑），保证可读性与加载速度。
- 她的气泡用文楷，用户的气泡用系统字体，一眼分得出谁在说话。

## 布局

- 桌面（≥960px）：左侧 84px 导航栏，中间舞台，右侧 420px 聊天栏。
- 手机（<960px）：上方舞台占 40dvh，下方聊天面板，导航变底部 Tab，处理了安全区。
- 375px 宽无横向滚动；触控目标不小于 44px；正文不小于 16px。

## 动效

CSS 动画为主：舞台光束、气泡、波浪、角色轻微上下浮动、气泡弹出。`prefers-reduced-motion` 下全部静止。

## 文案与标识

- 用“角色设定”的口吻，不说她有真实意识或情感。
- 舞台和聊天栏都带“AI 角色”标识。
- 她不扮演亲属，不索要验证码或银行卡信息，用户想走就让用户走。

## 角色形象

当前占位是代码绘制的原创鲸形立绘（`WhaleFigure`）。聊天接入时换成 three-vrm 渲染的 VRM 模型；模型文件和授权信息集中在 `src/avatar/model.config.ts`，换原创模型只改这一处。仓库不提交 `.vrm` 文件。
