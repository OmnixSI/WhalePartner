# 界面与美术规范

客户端（`apps/client`）的视觉方向叫“潮汐手帐”：一本放在海边的手帐，纸、墨、一条海平线，角色是页面上唯一鲜艳的东西。新增界面先查本文件。

## 取舍

做减法比做加法重要。早期版本用了毛玻璃卡片、渐变按钮、发光徽标、上浮的气泡和英文斜体小标题，每个单独看都还行，放在一起就是随处可见的“AI 应用”模板。现在去掉了这些：

- 没有毛玻璃、渐变和发光阴影；层次靠一像素的线和留白。
- 没有胶囊徽标和圆形图标按钮；标签是细边小方框，按钮是文字。
- 导航只有文字，不用图标；页面标题前不加英文小标题。
- 一个页面只有一种强调色，且随角色变；珊瑚色只用在错误和“忘掉”这类要小心的操作上。
- 圆角只有 6 和 10 像素。

## 配色

定义在 `apps/client/src/styles/tokens.css`。亮色是纸，暗色是夜里的海；设置页可选“跟随系统 / 晨光 / 深海”。

| 角色 | 亮色 | 暗色 |
|---|---|---|
| 底（纸） | `#f4f1e8` | `#0e1a26` |
| 聊天页 | `#faf8f2` | `#111f2d` |
| 墨（正文） | `#17222d` | `#e9e4d6` |
| 次要文字 / 说明 | `#55616c` / `#858e96` | `#a9b1b6` / `#7b858d` |
| 分隔线 | 墨色 14% | 纸色 14% |
| 强调色 | 随角色，取深色 | 随角色，取浅色 |

强调色：鲸汐 `#1f6f78`、大肥鱼 `#3552c9`、小克 `#b4532f`、小智 `#0f7c63`（暗色下分别提亮）。海平线两层浪用强调色混进纸色得到，所以换角色背景也跟着变。纸面有一层很淡的颗粒（`body::after`），只为了不那么平。

## 字体

- 角色说的话、标题、日记正文：霞鹜文楷（LXGW WenKai，OFL），按 unicode-range 分片加载，首屏只下载用到的字。
- 界面其余部分：系统 UI 字体（PingFang SC / 微软雅黑）。
- 她说的话是衬线体并带一条强调色细线，你说的话是无衬线并放进浅底小块：一眼分得出谁在说话，不靠气泡颜色。
- 小标签 12 像素，字距略放宽；日期和数字用等宽数字。

## 布局

- 桌面（≥960px）：左侧文字导航，中间舞台，右侧 420px 聊天页，聊天页贴边、只有一条竖线，不浮起。
- 内容页（日记、记忆、设置）：靠左的单栏，最宽 760px，用细线分段，不装进卡片。
- 手机（<960px）：上方舞台占 40dvh，下方聊天页，导航变底部文字栏，处理了安全区。
- 375px 宽无横向滚动；触控目标不小于 44px；正文不小于 15px，聊天文字 15 到 17px。

## 动效

只留三处：角色轻轻上下浮动，浪很慢地漂，新消息淡入。`prefers-reduced-motion` 下全部静止。

## 背景

首页是纸色的天加两层平涂的浪；日记、记忆、设置只有纸。没有光束、气泡和渐变。

## 文案与标识

- 用“角色设定”的口吻，不说她有真实意识或情感。
- 聊天页顶部带“AI 角色”标签；同人角色在舞台标题下注明“同人演示”。
- 她不扮演亲属，不索要验证码或银行卡信息，用户想走就让用户走。

## 角色形象

形象是 three-vrm 渲染的 VRM 模型。模型清单在 `apps/client/models.manifest.json`，文件不进仓库，用 `pnpm fetch-model` 下载并校验。目前都是别人做好的现成模型，授权没有核对，只作内部展示，对外发布前要换成原创或授权明确的形象。加载失败时显示代码绘制的原创鲸形占位图。
