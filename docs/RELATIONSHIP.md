# 关系进度与短期情绪

关系进度与卡面阶段保存在聊天 SQLite 数据库。它跨人格共享，但只有大肥鱼成功完成的一轮用户对话会增加好感度；每轮 +1 点，本地自然日最多 +10 点。取消、失败和主动消息不计分，同一条 assistant 消息只能记一次。

| 阶段 | 好感度 | 卡面效果 |
|---|---:|---|
| 1 · 相识 | 0 | 基础卡面 |
| 2 · 相熟 | 25 | 立体效果 |
| 3 · 默契 | 100 | 动态画面 |
| 4 · 亲近 | 250 | 专属特效 |

好感度不会随时间下降。四档卡面只使用关系进度读取结果，锁定高级效果不会阻止选择基础角色。

短期情绪按人格各自保存，来自该人格实际完成的回复。查询时按 100 分钟线性恢复到中性；不离线扣分、不影响回复内容、不改用户设置。模型当前支持 `neutral`、`happy`、`sad`、`angry`、`surprised` 和 `relaxed` 六种回复情绪。

API：`GET /api/relationship?character=deepseek` 返回共享 `points`、当前 `level`、下一阈值、进度百分比及所选人格当前恢复后的情绪。新增表使用 `CREATE TABLE IF NOT EXISTS`，不重写既有聊天行；旧库迁移测试会先创建旧格式数据库，再验证原聊天与新增状态均可保留。
