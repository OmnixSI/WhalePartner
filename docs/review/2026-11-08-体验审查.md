# 02 进程生命周期审查（WhalePartner / 鲸汐 v0.2.6）

结论：Tauri 外壳**完全不管后端**，后端是用户手动（或 .command）拉起的独立进程，与 App 生命周期零绑定。「关窗≠退出」「后端永不停」是架构缺失，不是单点 bug。

## 目标设计

### 总体
1. 后端编译为单文件 sidecar（推荐 Node SEA，因已用 `node:sqlite`、`node >=26`；`node --build-sdea`/`postject` 注入 blob，或 `bun build --compile`，但 `node:sqlite` 兼容需实测）。注意 `playwright-core` 不带浏览器、`@huggingface/transformers` 的模型文件（`models.manifest.json`）应放 `resources` 或首次运行下载到 app data；FFmpeg 同样走 `externalBin` 或首启下载。
2. Rust 在 `setup` 里起 sidecar，等健康检查通过再 `show` 主窗口（窗口配置 `"visible": false`）。
3. 默认语义：关最后窗口 = 退出 = 杀后端。可选「后台继续逛」。

### tauri.conf.json

```json
"app": { "windows": [{ "label": "main", "visible": false, "title": "鲸汐 · WhalePartner" }],
  "security": { "csp": "... connect-src 'self' http://127.0.0.1:* ipc: http://ipc.localhost ..." } },
```

### src-tauri/src/lib.rs（骨架）
```rust
use std::sync::Mutex;
use tauri::{Manager, RunEvent, WindowEvent};
use tauri_plugin_shell::{process::CommandChild, ShellExt};

struct Backend { child: Mutex<Option<CommandChild>>, port: u16 }
struct Bg(Mutex<bool>); // 「后台继续逛」

fn free_port() -> u16 { std::net::TcpListener::bind("127.0.0.1:0").unwrap().local_addr().unwrap().port() }

fn spawn_backend(app: &tauri::AppHandle, port: u16) -> CommandChild {
  let dir = app.path().app_data_dir().unwrap();
  let (mut rx, child) = app.shell().sidecar("whale-api").unwrap()
    .env("API_PORT", port.to_string())
    .env("APP_DB_PATH", dir.join("app.db"))
    .env("MEMORY_DIR", dir.join("memory"))
    .env("SURF_DIR", dir.join("surf"))
    .spawn().unwrap();
  // 日志落盘；子进程意外退出 → 带次数上限地重启
  tauri::async_runtime::spawn(async move { while let Some(_ev) = rx.recv().await { /* 写 api.log / 处理 Terminated */ } });
  child
}

pub fn run() {
  let app = tauri::Builder::default()
    .plugin(tauri_plugin_single_instance::init(|app, _, _| {
      if let Some(w) = app.get_webview_window("main") { let _ = w.show(); let _ = w.set_focus(); }
    }))
    .plugin(tauri_plugin_shell::init())
    .plugin(tauri_plugin_opener::init())
    .setup(|app| {
      let port = free_port();
      let child = spawn_backend(app.handle(), port);
      app.manage(Backend { child: Mutex::new(Some(child)), port });
      app.manage(Bg(Mutex::new(false)));
      // 把端口注入前端，并轮询 /api/health，通过后 show 主窗口
      let h = app.handle().clone();
      tauri::async_runtime::spawn(async move { wait_health(port, 30).await; if let Some(w) = h.get_webview_window("main") { let _ = w.show(); } });
      build_tray(app.handle())?; // 仅 Bg=true 时可见，菜单：打开 / 退出鲸汐
      Ok(())
    })
    .on_window_event(|win, ev| {
      if let WindowEvent::CloseRequested { api, .. } = ev {
        if *win.app_handle().state::<Bg>().0.lock().unwrap() {
          api.prevent_close(); let _ = win.hide();          // 后台模式：只隐藏
        } else {
          win.app_handle().exit(0);                          // 默认：真退出
        }
      }
    })
    .build(tauri::generate_context!()).expect("build");

  app.run(|app, ev| match ev {
    RunEvent::ExitRequested { api, .. } => {
      // Cmd+Q / 托盘「退出」都走这里：先杀后端再放行
      if let Some(c) = app.state::<Backend>().child.lock().unwrap().take() { let _ = c.kill(); }
      let _ = api; // 不 prevent_exit，直接退出
    }
    RunEvent::Exit => { /* 兜底再 kill 一次 */ }
    _ => {}
  });
}
```
要点：后台模式下 `RunEvent::ExitRequested` 若 `code.is_none()`（来自“最后窗口关闭”）才 `api.prevent_exit()`；显式退出（托盘/Cmd+Q，`code==Some`）才放行。

### 后端侧（apps/api）
- `server.ts` 增加：`process.on('SIGTERM'|'SIGINT', () => server.close())`，并在 stdin 关闭或父进程消失时自退出（防孤儿）：`process.stdin.on('end', () => process.exit(0))`。
- `server.listen` 前后加 `server.on('error')`，`EADDRINUSE` 时打印明确信息并以特定退出码退出（Rust 据此换端口重试）。
- 新增 `GET/POST /api/runtime`，把 `surfEnabled`（`config.ts:75`）改为可运行时切换；后台模式关闭时，窗口隐藏即调用 `surf` 的 `stop()`（`surf/scheduler.ts:100`），仅用户在场时冲浪。

### 前端（apps/client）
- `lib/api.ts:4` 改为 `await invoke('get_api_base')`（Tauri command 返回 `http://127.0.0.1:{port}`），`lib/net.ts:10` 同步。
- `useSharedChat.ts:83-89`：启动前 N 秒（或 `health===undefined`）不显示离线，改用 splash「她正在醒来…」，之后指数退避轮询。
- 设置页新增开关「关闭窗口后让她在后台继续逛」（默认关）；开启时弹一次说明：会在菜单栏常驻、持续联网与耗用模型额度；菜单栏图标提供「打开 / 暂停冲浪 / 退出鲸汐」。

### 迁移与验收

# 03 形象渲染审查（Live2D / VRM）

## 先说结论（与诉求不同的事实）
- 全仓库只有 **1 个** Live2D 模型（大肥鱼 `c_0120.model3.json`，`model.config.ts:12-13`，Cubism 4）。其余 22 个全是 VRM。所以「很多 F2D 渲染不对」大多是：模型文件缺失 / Cubism Core 缺失 / 想换别的 Live2D 模型但代码只支持 Cubism 4。

**A. 单例 + 彻底销毁（Live2D）**
```ts
// live2d/runtime.ts
const cache = new Map<string, Promise<Live2DModel>>();
export function getModel(url: string) {
  let p = cache.get(url);
  if (!p) { p = Live2DModel.from(url, { autoUpdate: false, autoInteract: false }); cache.set(url, p); }
  return p;
}
// 组件内：先 await getModel，再建 app，避免白占上下文
app = new PIXI.Application({ view: canvasRef, backgroundAlpha: 0, autoDensity: true,
  resolution: Math.min(devicePixelRatio, 2), antialias: false, sharedTicker: true, powerPreference: "high-performance" });
// cleanup

const gl = (app.renderer as PIXI.Renderer).gl;
gl?.getExtension("WEBGL_lose_context")?.loseContext();
```

**D. 点击：HitArea + 包围盒兜底 + 动作优先级**
```ts
model.on("pointertap", (e) => {
  const p = e.data.global;
  const areas = model.hitTest(p.x, p.y);            // 返回命中的 HitArea 名
  const region = areas[0] ?? bboxRegion(model, p);  // 无 HitAreas：按包围盒 上1/3=Head 中=Body 下=Legs
  playTap(region);
});
async function playTap(region: string) {
  clearTimeout(watchdog);
  const action = chooseTapAction(tapActions) ?? fallbackAction;
  watchdog = setTimeout(() => finish(true), 4000);   // 防锁死
  const ok = await model.motion(action.group, action.index, MotionPriority.FORCE);
  if (!ok) { await model.expression(randomExpr()); finish(true); }
}
```

## 升级建议
当前 `pixi-live2d-display@0.4.0` + `pixi.js@6.5.10` 已停止更新。建议：
1. **短期（本轮）**：先不换库，只做上表 P0/P1（销毁、ticker、点击锁死、懒加载动作），收益最大、风险小。
2. **中期**：评估 `untitled-pixi-live2d-engine`（维护中，支持 Pixi 7/8、Cubism 2/3/4/5、Core 版本兼容更好）。理由：修复 Cubism 5 兼容、减少对 Pixi 6 的依赖。`pixi-live2d-display-lipsyncpatch` 只在 0.4 基础上补口型，改动小但仍是 Pixi 6，对本项目"口型 + Cubism 4"够用。取舍：若只保留这 1 个 Cubism 4 模型，维持 0.4 即可；若计划接更多第三方模型（含 Cubism 2/5），换 untitled 引擎。未实测，迁移前需用 `c_0120` 验证遮罩与 CSP（`@pixi/unsafe-eval`，`tauri.conf.json:25` 没有 `unsafe-eval`）。

## 修复片段

A. 键位（桌面 Enter 发送，保留 IME 保护）

```tsx
const isTouch = matchMedia("(pointer: coarse)").matches;
const onKeyDown = (e: KeyboardEvent<HTMLTextAreaElement>) => {
  if (e.key !== "Enter" || e.nativeEvent.isComposing || e.keyCode === 229) return;
  const wantsSend = isTouch ? (e.metaKey || e.ctrlKey) : !e.shiftKey;
  if (!wantsSend) return;           // Shift+Enter / 触屏 Enter => 换行
  e.preventDefault();
  submit();
  ref.current?.focus();
};
```

B. 草稿持久化 + 停止按钮

```ts
// useSharedChat
const key = `wp:draft:${characterId}`;
const [draft, setDraft] = useState(() => sessionStorage.getItem(key) ?? "");
useEffect(() => { sessionStorage.setItem(key, draft); }, [key, draft]);
```
```tsx
<button onClick={busy ? onStop : submit} aria-label={busy ? "停止" : "发送"}>
  {busy ? <Icon name="stop" /> : <>发送<Icon name="send" /></>}
</button>
```
`onStop = () => abort.current?.abort()`；abort 分支改为保留已有文字：`status: turn.text ? "done" : …`，不要 `filter` 掉。

C. 流式合帧（降低重渲染）

```ts
const buf = useRef(""); let raf = 0;
const flush = () => { raf = 0; const t = buf.current; buf.current = "";
  setLive(p => p && { ...p, chunks: [...p.chunks, t] }); };
// delta 里：buf.current += event.text; raf ||= requestAnimationFrame(flush);
// turns 仅在 done 时一次性写入完整文本
```

D. 服务端早发 ack，降低"黑屏等待"

```ts
startSse(response);
sendSse(response, "ack", { sessionId });   // 立刻让前端进入 thinking 且可靠
```
