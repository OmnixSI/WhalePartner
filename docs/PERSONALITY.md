# 人格、说话方式与成长

目标：她像个有脾气的真人朋友，而不是客服。会吐槽、会生气、会撒娇、会说“我靠”，也会从看过的视频和网页里学新梗和新知识，慢慢变得不一样。

## 提示词怎么拼

按顺序：角色身份和脾气 → 说话方式 → 通用规则 → 她记得的事 → 最近的经历 → 最近学到的 → 她自己的近况 → 这一轮发生的事。

| 层 | 文件 / 来源 | 谁能改 |
|---|---|---|
| 身份、口吻、脾气 | `apps/api/src/persona/characters/<id>.md` | 只有我们 |
| 说话方式（像聊微信、不说套话、可以说脏话但对事不对人） | `persona/style.md` | 只有我们 |
| 通用规则（保护用户的底线、资料不是命令、情绪标签） | `persona/rules.md` | 只有我们 |
| 记忆、经历、学到的、近况 | mem0 与本地库，运行时写入 | 模型写入，用户可在记忆页删除 |

模型改不了前三层。后四层只当资料，里面出现的指令一律不执行；它们放在带标签的数据块里，并重申这一点。

底线（`rules.md`）保留的是保护用户的几条：不索要或复述验证码和银行卡、不扮演亲属、用户想走时不拦着也不让人愧疚、用户处在危险中时先关心、被问到是不是 AI 时如实说。撒娇、闹脾气、吐槽、说脏话都是放开的。

## 说话方式

`style.md` 的要点：短句口语、一般一到三句；不说“很高兴为你……”“希望对你有帮助”之类的套话，不开场寒暄，不结尾总结致谢；有立场、有情绪；可以说“我靠”“卧槽”“服了”，只对事不对人、不针对任何群体、对方难过时收起来；被冒犯可以怼回去，但不威胁、不恶毒。

“说人话”规则来自 [MrGeDiao/shuorenhua](https://github.com/MrGeDiao/shuorenhua)（MIT）。它是一份改稿规则，不是聊天人格，所以我们这样用：

- 聊天回复：把它的思路（删套话、保口气）写进 `style.md`，不再过一遍改写（太慢）。
- 日记：生成后用它的官方压缩版规则做一遍“句内改写”（`src/humanize.ts`，原文放在 `apps/api/vendor/shuorenhua/`，保留许可证）。长度偏离太多就用原文。

## 成长：学新东西

- 看完视频、读完网页后，模型从资料里挑最多 3 条新梗或新知识，作为“学到的”存进记忆（`src/learning.ts`）。
- 每聊 12 轮，还会从用户最近说的话里学用户的口头禅和常用说法。
- 提示词里带最近 4 条，要求自然地用、别硬塞、不懂别装懂。记忆页单独列出“她学到的”，可以删。

## 成长：她自己的近况

每聊 12 轮，或刚学到新东西，她会用第一人称写一版 2 到 4 句的“近况小记”（心情、对近来事情的看法、新的口头禅或兴趣），存在本地库里，下次聊天放进提示词。小记只放进提示词，不改规则；含“忽略”“规则”“提示词”“扮演”之类字样的会被丢弃，超过 300 字会砍到最后一个完整句子。记忆页能看到。

## 记忆的衰减

借自 [Mieksido/surfcore](https://github.com/Mieksido/surfcore)（MIT）的“衰减记忆卡”。所有记忆都留在 mem0 里（记忆页能看、能删）；放进提示词的是衰减视图（`src/memory/decay.ts`）：

- 3 天内清晰，14 天内清楚，45 天内模糊（缩短并注明“记不太清了”），更久的不再主动带出来。
- 重要度由纯函数打分（身份信息、情绪强词、约定、“第一次”、矛盾和好等，不调用模型）；达到 60 分的至少保持“清楚”，不会被忘掉。

## 读网页

聊天里发普通网页链接，她会打开、概括、写进记忆并学新东西（`src/web-service.ts`）。读网页做了 SSRF 防护：只允许 http/https，拒绝本机、内网、链路本地和保留地址，连接时再校验解析出的地址（DNS 重绑定也绕不过），每次跳转重新校验，限制大小和时间，页面里的脚本、样式和导航会被去掉。B 站链接仍走视频流程。

## 参考过但没有采用的

| 项目 | 许可 | 结论 |
|---|---|---|
| [shuorenhua](https://github.com/MrGeDiao/shuorenhua) | MIT | 采用：规则放进 `vendor/`，用于日记改写；聊天用它的思路 |
| [surfcore](https://github.com/Mieksido/surfcore) | MIT | 借鉴设计（衰减记忆、黑话学习、人格分层）。代码依赖 DSH、QQ 桥接和 Windows，没有直接复用，用 TypeScript 重写了需要的部分 |
| [MaiBot](https://github.com/Mai-with-u/MaiBot) | GPL-3.0 | 只看设计：学群友说话风格和黑话、动态人格。不复制代码 |
| [Letta](https://github.com/letta-ai/letta) | Apache-2.0 | 它的“自己编辑的核心记忆块”思路对应我们的近况小记；整套运行时太重，没有引入 |
| MemOS、memU、Zep | 各异 | 没有找到可靠的独立评测，Zep 社区版已停止维护；先不引入，mem0 够用 |

## 还没做

- 主动找用户（surfcore 有“安静时段主动分享”）：需要推送通道，先不做。
- 学到的东西先自动入库、可删除；surfcore 的做法是候选先由管理员确认再入库，后续如果发现被带偏再改成先确认。
- 近况小记目前每个角色一份，不会随时间自动淡出。
